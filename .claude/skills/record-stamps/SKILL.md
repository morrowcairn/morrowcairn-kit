# Record stamps

**Loaded:** when a task matches the description above; Claude Code reads it from this folder.

## 9. A time stamp comes from the clock, in the command that writes it

1. Read the time from the clock in the same command that writes the record: `date` in that command,
   or a placeholder the command fills from the clock.
2. Never type a time, and never copy one from an earlier `date` run.
3. A tool that can't read the clock (an editor tool, a memory note) writes no time. Put the time in
   a record stamped as above, and point to that record.

**Would revisit if:** every tool that writes a record stamps the time itself.
