# kit-manifest.txt -- the class of every tracked file: whether it travels to a spawned project, and who owns
# it there.
#
# Read by tools/install-release.sh: an install ships everything not classed kit, and its CLASSES file
# carries each shipped file's class, which patterns/local-spawn.md, patterns/local-upgrade.md and the
# hooks' checked-copies layer read.
# One entry per line: CLASS PATH. A PATH ending in "/" covers everything under that directory.
# Lines starting with "#" are comments. Blank lines are ignored.
#
#   kit    stays in the kit and is never copied to a spawn: it describes, tests or licenses the kit itself (the
#          kit's own CLAUDE.md is the kit's sessions' file, and a spawn's comes from templates/; LICENSE covers
#          the kit only, and a spawn chooses its own; kit.binaries turns the binary scan on for the kit's own
#          pushes, and a project turns its own on; .github/secret_scanning.yml is the kit's repositories' GitHub
#          setting for the kit's own fixture; kit.list-id names the kit's own do-not-publish list, and kit-pin
#          gives each project its own)
#   spawn  copied once, at spawn; the spawn owns it from then on, and an upgrade never overwrites it. A file
#          under templates/ lands at the spawn's top level under its own name (templates/CLAUDE.md -> CLAUDE.md)
#   owned  kit-owned: ships in the install and runs from there, and a project holds no copy. A copy it does
#          hold must equal the release's, or be declared in kit.forks (the checked-copies layer)
#   example  a code pattern: ships in the install for a project to copy and change as its own. Nothing copies it
#          into a project, and the checked-copies layer doesn't police a copy. Listed before owned patterns/, since
#          the first entry that matches a path decides its class
#
# EVERY tracked path is covered, by its own entry or by its directory's. tests/kit_docs_test.sh fails on
# a tracked path no entry covers (K18): a file added without a class would otherwise travel to every
# spawn by default, unreviewed. Directories are listed whole where all their files share a class, and
# files one by one only where they don't (tests/). tools/install-release.sh classes a path no entry covers
# as "owned".
