# refusals.txt -- a name for each refusal the kit's gates print, one per line, tab-separated:
#   NAME	EXIT	WHAT
# NAME is <gate>/<reason>, and the refusal prints it in brackets after REFUSING or BLOCKED:
#   pre-push: REFUSING [pre-push/no-list] -- LEAK_PATTERN is not configured: this project has no list at ...
# <gate> is the file that refuses. The checked-copies layer, check-copies.sh, prints under the hook that runs it:
#   pre-commit: REFUSING [check-copies/differs] -- kit-owned file(s) differ from release ...
# The history audit's closing verdict carries its name the same way:
#   REFUSING [kit-history-audit/hits]: 2 hit(s) outside the allow file, each named above; ...
# EXIT is the gate's exit status when it refuses so: a number, or 1+ for 1 or another non-zero status that varies.
# WHAT says it plainly.
# A gate is listed once every refusal it prints carries a name (kit_docs RN0 to RN2 check this file against the gates).
